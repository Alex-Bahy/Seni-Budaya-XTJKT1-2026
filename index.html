🔧 Panduan Setup (2 Spreadsheet)

Setiap semester punya spreadsheet sendiri dan Apps Script sendiri:

• Ganjil → SHEET_ID = 1pBPOgP6t-…jzszW_rbg
• Genap → SHEET_ID = 1noua8iuSK2W…E2pNTHk

Langkah: buka tiap spreadsheet → Extensions → Apps Script → tempel Code.gs yang sesuai → Deploy → New Deployment → Web App (Execute as: Me, Access: Anyone).

Salin URL Web App masing-masing, lalu isi GAS_URLS.Ganjil dan GAS_URLS.Genap di bagian atas script halaman ini.

Saat semester diganti, tabel nilai dan konfigurasi otomatis dikosongkan lalu dimuat ulang dari spreadsheet semester yang dipilih.
